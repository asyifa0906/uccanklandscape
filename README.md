# UCCANK'S LANDSCAPE

Website UCCANK'S LANDSCAPE merupakan website untuk memberikan informasi mengenai jasa pembuatan taman dan kolam serta produk tanaman, rumput, dan bunga.

## Teknologi

- HTML5
- Bootstrap 5.3.8
- Bootstrap Icons
- JavaScript

## Halaman Website

- Beranda
- Layanan
- Produk
- Kontak

## Fitur

- Informasi jasa pembuatan taman
- Informasi jasa pembuatan kolam
- Daftar produk
- Harga produk
- Galeri foto produk
- WhatsApp
- Lokasi usaha

## Tujuan

Website ini dibuat sebagai tugas Pemrograman Web dengan menggunakan framework Bootstrap.
